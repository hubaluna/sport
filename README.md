# FORGE / 8 (v5.2) — Мобільний тренер силових тренувань

Українськомовний автономний PWA-застосунок силових тренувань, підтягувань та CrossFit-комплексів на **React 19 + TypeScript + Vite + Tailwind CSS v4** з можливістю збірки в єдиний автономний HTML-файл.

🌐 **Онлайн-версія на GitHub Pages:** [https://hubaluna.github.io/sport/](https://hubaluna.github.io/sport/)  
📦 **Автономний файл:** `FORGE-8-single.html` (працює локально через `file://` без сервера та інтернету)

---

## Основні можливості

1. **Мобільна ергономіка (100dvh):**
   - Темна палітра: фон `#111310`, картки `#191D16`, вкладені елементи `#21271D`, акцент `#CEFA42`, текст `#F2F6EB` / `#9FA995`, попередження `#F2A98C`.
   - Шрифти: `Oswald` (заголовки й таймери), `Manrope` (інтерфейс), `JetBrains Mono` з `tabular-nums` (цифри, таймери, спліти).
   - Суворе дотримання `100dvh`: активний екран тренування вміщується без вертикального скролу.
   - 4 вкладки навігації: **«План»**, **«Щоденник»**, **«Тренер»**, **«Профіль»** (приховані під час активного заняття).
   - Без статичних pill-бейджів (роздільник `·`), тач-цілі ≥44px, жодних нативних `alert`/`confirm`/`prompt`.

2. **Черга занять без прив'язки до днів тижня (Rolling Queue):**
   - **3 дні на цикл:** циклічна черга `А → Б → В → А → ...` (підвищення рівня після 3 занять).
   - **4 дні на цикл:** циклічна черга `А → Б → В → Г → А → ...` (після 4 занять).
   - Зсув черги відбувається лише після фактичного завершення заняття.
   - 7-денна стрічка фактичної активності (крапки лише на реально виконаних днях зі Щоденника).
   - Кнопки «Почати заняття», «Обрати інше заняття» та «Давно не займався» (підказка при перерві ≥7 днів).

3. **Повне видалення заминки (`cooldown: null`):**
   - Етап заминки повністю видалено з усіх тренувальних днів і таймерів. Після останньої вправи заняття одразу завершується та записується в Щоденник.

4. **Глобальна авторегуляція повторень + рекорди:**
   - **Усередині тренування:** перевиконання `+2`/`+4` піднімає наступний підхід на `+1`/`+2` (`↑ +N за запасом`); недовиконання `≤ target - 2` адаптує решту підходів (`↓ адаптовано під темп`) і додає `+15 с` відпочинку.
   - **Глобально (`exerciseProgress`):** перевищення сумарного плану без провалів підвищує базову ціль вправи на `+1` на всі наступні дні (`А/Б/В/Г`).
   - Автоматична фіксація нових рекордів (`pushMax`, `strictMax`, `assistedMax`) із бейджем `🏆 Новий рекорд!`.

5. **Спеціальні режими:**
   - **«Давно не займався» (Втягувальне Full-Body):** 4-хв суглобова розминка + тяга резинки (~55%) + віджимання (`max(4, round(pushMax * 0.5))`) + 2×9 міст/випади + 2 підходи кора на 50–60%. Записується з тегом `Втягувальне (Full-Body)` без зсуву черги.
   - **WOD 22:00:** 5 раундів `(10 віджимань / 10 стрибків у планці / 5 вистрибувань / 10 прес)` із лічильником `Раунд X / 5`, фіксацією сплітів та автозбереженням.

6. **Таймери, звук, екран і сховище:**
   - Таймери на дельті `Date.now()`, аудіосигнали 3-2-1 через Web Audio API, Screen Wake Lock.
   - Автопауза при відкритті довідки техніки (окрім комплексу).
   - Чіпи резинки в `#profile` (опір + кріплення `Стопа`/`Коліно`) з парсингом старих форматів.
   - 100% зворотна сумісність `localStorage` (`forge8.mobile.v2`, `forge8.log.index.v1`, `forge8.log.<id>`, `forge8.recovery.backup.v1`), JSON експорт/імпорт та Base64-код бекапу.

## Команди розробки

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка продакшн-версії та автономного FORGE-8-single.html
npm run build

# Збірка лише автономного файлу
npm run build:single

# Запуск автоматичних тестів логіки та авторегуляції
npm test

# Перевірка типів TypeScript
npm run lint
```
